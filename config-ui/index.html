Show keyboard
Drag a key to move it. Dropping it onto other keys bumps them down a row to make room. Drag its right edge to make it wider. Drag across empty space to select several keys, or shift-click to add and remove keys from a selection, then move them together. Use the Key size slider in the Theme section for overall size.
Combo: join keys with a plus sign in the Key field (for example space+ctrl) to make one cap that flashes when both are pressed within the timing window. The ms field sets that window. This is great for inputs like the Apex Superglide.

Superglide
Show Superglide combo A ready-made timing combo for the Apex Legends Superglide. One cap that flashes only when you hit the input cleanly. Turn this on, then enter the two keys you use.
First key (jump) Pressed first
Second key (crouch) Pressed just after, within the window
Timing window (ms) How soon after the first key the second must land
Order matters: the first key (jump) must land before the second key (crouch), and the second must follow within the timing window. The window gets tighter at higher frame rates. One frame is about 16 ms at 60 FPS and about 7 ms at 144 FPS, so start near one frame for your FPS and adjust from there. Drag the SUPERGLIDE cap on the grid above to position it.
